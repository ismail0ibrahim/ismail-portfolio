سجل خاص

تفعيل سجل الزيارات

جيت هب بيدور الصفحة بس، ومش بيقدر يخزن الزيارات ولا يخبيها بكلمة سر جوه الملفات. عشان كده السجل بيتحفظ في Supabase، والقراءة بتتم بعد تسجيل دخولك.

المفتاح المكتوب في الإعدادات مفتاح سري. سيبه في لوحة Supabase ومتحطوش في الموقع.

  1. اعمل مشروع مجاني من supabase.com.
  2. من SQL Editor شغّل ملف supabase/visits.sql مرة واحدة.
  3. من Authentication اقفل تسجيل المستخدمين الجدد، وبعدين أضف مستخدم بإيميلك وكلمة سر، وفعّل Auto Confirm.
  4. من Project Settings ثم API انسخ Project URL والمفتاح العام anon أو publishable فقط.
  5. حط القيمتين في analytics-config.js وانشر الموقع.

إيميل الدخول لازم يكون لأنه مكتوب في سياسة القراءة. الصفحة بتعرض الدولة والمدينة والمصدر والجهاز، من غير عنوان IP ومن غير اسم الشخص.
